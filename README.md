# NetPilot

> 一个自动维护的 Shadowrocket（小火箭） 模块规则仓库，帮你保持国内直连、国外代理、广告拦截的平衡。

---

## ✨ 项目特点

- ✅ **自动更新**：每天定时从多个上游规则源拉取最新规则，自动合并、去重、过滤敏感域名。
- 🧩 **模块化设计**：直连规则与去广告/代理分流分成独立模块，自由组合。
- 🛡️ **隐私保护**：自动过滤银行、支付类域名，绝不加入 HTTPS 解密列表。
- 🔍 **安全标记**：自动识别广告/追踪域名，你可选择拉黑或保留。
- 📅 **日志可追溯**：每天按日期保存运行日志和危险域名快照，方便排查问题。
- 📱 **手机直接订阅**：模块链接永久有效，更新后 Shadowrocket 自动拉取。

---

## 📦 模块说明

### 1. NetPilot Direct

国内直连规则模块，包含大量国内网站、APP、CDN 域名，让国内流量直连，避免绕路。

- 支持银行、支付、微信、支付宝、抖音、京东等常见国内服务。
- 自动更新，规则数量可在模块外部查看。

### 2. NetPilot Shield

去广告 + 代理分流模块。

- 包含国内外广告拦截规则、追踪域名拦截。
- 内置微博、微信等去广告脚本（需开启 HTTPS 解密）。
- 代理分流部分可手动添加或由上游更新。
- 自动过滤银行/支付类域名，保护隐私。

---

## 🚀 快速开始

在 Shadowrocket 中添加以下模块订阅链接：

| 模块 | 链接 |
|------|------|
| 直连模块 | [NetPilot_Direct.module](https://raw.githubusercontent.com/Unwhimsical/NetPilot/refs/heads/main/modules/NetPilot_Direct.module) |
| 去广告/代理模块 | [NetPilot_Shield.module](https://raw.githubusercontent.com/Unwhimsical/NetPilot/refs/heads/main/modules/NetPilot_Shield.module) |
| 主规则配置 | [NetPilot Route.conf](https://raw.githubusercontent.com/Unwhimsical/NetPilot/refs/heads/main/NetPilot%20Route.conf) |

添加后，建议在 Shadowrocket 中将全局路由设置为“配置”，并按需开启 HTTPS 解密（仅解密去广告脚本涉及的域名）。

---

## 🔄 更新机制

- 通过 GitHub Actions 每天 **北京时间 12:00 和 00:00** 自动运行。
- 从多个可信上游源拉取规则，自动清洗、合并、去重。
